# Repository guidance

This repository contains runtime core, the 1C extension, Jupyter, MCP, and VS Code. Keep product behavior in the component that owns it: `src/onec_runtime` for execution and state, `packages/jupyter` for notebook integration, `packages/mcp` for agent transport, and `packages/vscode` for editor integration. Check nested `AGENTS.md` before editing a component.

The checked-in notebooks under `notebooks/demo/ZUP` target **ЗУП КОРП 3.1.38.92** with a data snapshot dated **01.08.2021**. Treat those as separate version and data facts. The notebook under `notebooks/demo/UT` targets **УТ 11.6.1.61** and derives its period from the infobase data. Generated acceptance notebooks belong in `tests/fixtures/notebooks`; regenerate them with the corresponding `tools/build_*_notebook.py` script and keep outputs/execution counts empty.

Never commit real 1C infobases, exported customer configuration, credentials, raw live evidence, or local paths from a run. Small reviewed regression fixtures under `tests/fixtures` may contain only the fields a test needs. `artifacts/`, `.runtime/`, `.venv/`, and `node_modules/` are local outputs. Run focused tests for a change first. Live 1C tests are opt-in and need an installed platform and temporary infobase; do not describe static tests as live qualification. Parser-generator checks use the pinned source in `tests/fixtures/parsergen`; `ONEC_PARSERGEN_SRC` is an optional override.
